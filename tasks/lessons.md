# Lessons

## 2026-07-27 — Demo script tone

- Avoid generic AI-demo contrast lines such as “No fake loading reel.” Describe the visible product behavior directly and let the evidence establish credibility.
- Do not frame multi-wallet comparison as necessarily one person's accounts. Alter Ego supports comparison across any selected wallets; same-owner, team, peer, and cohort comparisons are all valid use cases.
- Never reuse legacy public demo wallets for the submission video without explicit approval. The demo cohort must be selected for the intended real-user story and verified before capture.

## 2026-07-28 — Plan completion status

- When a request explicitly limits implementation to one task, report that the remaining roadmap is still incomplete. Do not imply that the full Composite Trading Pattern or trading system exists from its foundation layer alone.

## 2026-07-28 — Implementation visibility

- When the user asks to see work as it happens, do not continue background subagent execution. Work sequentially and report each red test, implementation change, green test, and review gate in the commentary stream.

## 2026-07-30 — Approved-plan autonomy

- After the user approves a design and implementation plan, continue task-by-task without asking for redundant permission; report verification gates in commentary instead.
