## 1. Project Overview

### One-Liner
A TEE-bound agent that reads your entire on-chain history across every wallet and chain, shows you what you're good at (amplify) and what's costing you money (guard), then cross-references top traders. Your Ethereum self and Solana self face off in a roast battle built on real data.

### Problem Statement
Crypto traders have no objective mirror reflecting their patterns across all their wallets and chains. They remember the wins, forget the losses, and never see the full picture. A trader with 3 wallets across 2 chains has 7,000+ transactions — and no tool that synthesizes them into a coherent trading identity. The crowd tells them what to do. Nobody tells them who they ARE.

### Solution
Alter Ego ingests your complete on-chain history via OnchainOS across every wallet you own (multi-address) and every chain you've used (multi-chain: Ethereum, Solana, X Layer). It classifies patterns into AMPLIFY (what you're good at, with dollar values attached) and GUARD (what's costing you money, with exact loss amounts). Self-learning comes FIRST — you see yourself clearly for the first time. THEN it cross-references top-performing leaderboard traders to show you the gap. The demo hook: your own ETH self and SOL self face off in a roast battle built on real on-chain data.

### Why This Wins

| Judging Criterion | How We Excel |
|---|---|
| Product Experience & Completeness | Full end-to-end flow: wallet auth → multi-chain ingestion → pattern classification → persona → crowd comparison → roast battle. 90s of pure value, no filler. |
| Creativity | Nobody is building a trading IDENTITY agent. Eat This? does food. WorldCupCaller does predictions. CertiK does security. Alter Ego builds your on-chain persona — the roast battle is the most theatrical demo in the hackathon. |
| Revenue / Orders / Reviews | x402 micropayments: Snapshot ($0.99), Coach ($4.99/mo), Battle ($1.99). Listed on OKX.AI marketplace with real pricing. |
| Category Excellence | Lifestyle Companion has only ~2 ASPs listed. Alter Ego fills an empty lane with a novel product. Social Buzz crossover is natural — the roast video IS the X post. |

## 4. Technical Specifications

### Pattern Classifier
- **Purpose:** Detect 12 trading patterns (6 AMPLIFY, 6 GUARD) from OnchainOS transaction data
- **Interface:** `classifyPatterns(trades: Trade[], approvals: Approval[], pnl: PnLData[]): PatternResult`
- **Key Data Structures:** `Trade { timestamp, token, amount, pnlPct, pnlUsd, holdDurationDays }`, `Pattern { id, tag, type: 'AMPLIFY'|'GUARD', confidence: 'HIGH'|'MEDIUM'|'LOW', evidence: Trade[], costUsd, insight }`
- **Dependencies:** OnchainOS portfolio data, market PnL data, security approval data
- **Constraints:** Rule-based (not ML), deterministic, runs in <2s for 7,000+ transactions
- **Patterns:**
  - AMP-01: Patient Accumulator — avg hold > 30 days, PnL positive
  - AMP-02: Disciplined Defender — stop-loss hit rate > 70%
  - AMP-03: Meme Sniper — tokens < 24h old, >50% win rate
  - AMP-04: Early Bird — entries within 3h of launch, positive PnL
  - AMP-05: Diamond Hands — held through >50% drawdown, recovered to profit
  - AMP-06: Consistent Compound — ≥5 profitable trades, ≤20% drawdown
  - GRD-01: HODL Trap — ≥3 trades held past -40%, >7 day hold
  - GRD-02: Paper Hands — ≥5 panic sells within 2h of buying
  - GRD-03: Gas Guzzler — avg gas >2x network median
  - GRD-04: Blind Signer — >5 unverified contract approvals
  - GRD-05: Rug Roulette — >40% micro-cap trades rugged or -90%+
  - GRD-06: Top Buyer — ≥3 buys within 5% of ATH, then -20%+

### Persona Engine
- **Purpose:** Generate trading persona from pattern tags
- **Interface:** `generatePersona(patterns: PatternResult): Persona`
- **Key Data Structures:** `Persona { archetype, catchphrase, vice, superpower, kryptonite, tradingStyle, emojiSignature }`
- **Dependencies:** Pattern Classifier output only

### Chat UI
- **Purpose:** Terminal-style interface with typing animations, data cards, persona reveals
- **Interface:** React component tree using Framer Motion for animations
- **Dependencies:** Tailwind CSS, Framer Motion, Lucide React icons

### API Layer
- **Purpose:** Next.js API routes bridging frontend ↔ OnchainOS CLI
- **Endpoints:**
  - `POST /api/analyze` — wallet ingestion + pattern classification
  - `GET /api/persona` — persona from cached tags
  - `GET /api/compare` — crowd comparison data
  - `GET /api/roast` — pre-generated roast lines
- **Dependencies:** OnchainOS CLI, Node.js `child_process.execSync`

### OnchainOS Integration
- **Purpose:** All blockchain data ingestion
- **Commands:** See INTEGRATION-DEEP-DIVE.md for exact CLI commands
- **Dependencies:** OKX API keys, Agentic Wallet login

## 5. API Contracts

### External API: OnchainOS CLI

**Authentication:** Agentic Wallet (email + OTP, TEE session key)
**Rate Limits:** Sandbox keys are rate-limited; dev portal keys recommended

#### Command: `onchainos portfolio all-balances`
- **Purpose:** Get all token balances for a wallet across chains
- **Request:**
  ```bash
  onchainos portfolio all-balances --address <addr> --chains "xlayer,solana,ethereum" --filter 1
  ```
- **Response:** Table with token name, symbol, balance, USD value, chain
- **Gotcha:** EVM and Solana addresses need separate calls

#### Command: `onchainos market portfolio-overview`
- **Purpose:** Get PnL overview for logged-in wallet
- **Request:**
  ```bash
  onchainos market portfolio-overview
  ```
- **Response:** `winRate`, `realizedPnl`, `top3Tokens`

#### Command: `onchainos leaderboard list`
- **Purpose:** Get top trader rankings
- **Request:**
  ```bash
  onchainos leaderboard list --chain solana --time-frame 3 --sort-by 1
  ```
- **Response:** Max 20 entries: `rank`, `walletAddress`, `pnl`, `winRate`, `txCount`, `volume`

#### Command: `onchainos security approvals`
- **Purpose:** Check ERC-20/Permit2 approvals for risky contracts
- **Request:**
  ```bash
  onchainos security approvals --address <addr>
  ```
- **Response:** List of approvals with contract addresses, amounts, risk flags
